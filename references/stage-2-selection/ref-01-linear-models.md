# Group 01 — Linear Models

## 1. Overview
Linear and logistic regression. The simplest transparent family.

## 2. Family Members
LinearRegression, LogisticRegression, Ridge, Lasso

## 3. Strengths
- Fully interpretable
- Extremely fast
- Stable with small data

## 4. Weaknesses
- Captures only linear relations
- Sensitive to outliers

## 5. Recommended Baseline
LogisticRegression or LinearRegression

## 6. Key Hyperparameters
C (1e-4 to 1e3), penalty (l1/l2), solver (heuristic, no source)
