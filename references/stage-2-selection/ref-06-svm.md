# Group 06 — SVM

## 1. Overview
Support Vector Machines: linear and kernel.

## 2. Family Members
SVC, SVR, LinearSVC, OneClassSVM

## 3. Strengths
- Effective in high-dimensional spaces
- Memory efficient

## 4. Weaknesses
- Poor on large datasets
- Sensitive to feature scaling

## 5. Recommended Baseline
SVC (RBF kernel, C=1.0, gamma=scale)

## 6. Key Hyperparameters
`C (1e-3 to 1e3), gamma (1e-4 to 1), kernel`
